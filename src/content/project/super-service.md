## Overview

**Super Service** is a two-sided services marketplace built in Flutter.
Customers post jobs, service partners place bids, and the platform manages
contracts, payments, messaging and reviews end to end.

## Key Features

- **Job posting & bidding** flow
- **Contracts** and milestone tracking
- **Partner wallet** with payment integration
- **Push notifications** via Firebase Cloud Messaging
- **Maps & location** for nearby service partners
- **Reviews & ratings**
- **Auth, profile and settings**, fully localised

## Tech Stack

- **Flutter** with Bloc + Hydrated Bloc, `go_router` and `get_it`
- **Supabase** backend (auth, database, edge functions)
- **Firebase Cloud Messaging** notifications
- **flutter_map / geolocator** for location
- **Paylink** payment integration
